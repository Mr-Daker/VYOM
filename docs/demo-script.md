# Rajkumar demo script (target: 2 minutes)

## 0:00–0:20 — Make the pain visible

“Sunita teaches 35 children across Grades 1–3. She cannot individually reconstruct every child’s missed learning while also keeping the rest of the room engaged.” Start the fixed demo and open attendance. Point to Rajkumar’s **Returning** badge and the note that absence is not treated as failure.

## 0:20–0:45 — Find the hidden gap

Save attendance and open the groups. “Today’s target is N6 subtraction. Rajkumar saw the addition introduction, missed later practice, and has only developing evidence for N4—so the system flags a possible prerequisite gap and asks the teacher to verify it.” Show the group explanation and the factor-by-factor teacher-first score.

## 0:45–1:15 — Protect teacher attention

Build the rotation. Show that Group A receives the teacher first, every group has a curriculum-grounded activity in all three rotations, and only available materials are used. Open one activity to show the source, quick check, edit, regenerate, and reject controls. Save a small edit and approve the plan.

## 1:15–1:45 — Close the evidence loop

Open Exit evidence and choose **Use demo evidence**. Explain that the teacher observed understanding and Rajkumar answered the N4 check correctly. Update mastery and regroup.

## 1:45–2:00 — Show the benefit

Point to: **0.45 → 0.80, Developing → Mastered**, and **Prerequisite recovery → Concept launch**. “The value is not a generated worksheet. It is a workable class today and a better decision tomorrow, based on actual evidence.”
